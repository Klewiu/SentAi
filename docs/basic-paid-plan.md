# Ceny planow

Aktualna konfiguracja i instrukcja importowania cen: [stripe-price-catalog.md](stripe-price-catalog.md).

Basic startował od 100 PLN / 25 EUR rocznie. Kwoty nie są narzucone; administrator tworzy cenę w Stripe, a następnie importuje jej Price ID w panelu aplikacji. Manual pozostaje dostępny tylko dla Pro.
